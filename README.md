A short text that leaves the reader more relaxed: slow water, an old stone,
and a river widening until the sky lies down in it. The calm is shown rather
than instructed, in plain gentle words with a slow rhythm.

`main.ts` writes the text to `/output/entry.txt` (UTF-8, 172 code points, within
the 1-280 code point gate, not whitespace). It runs in a sandbox with no network.
